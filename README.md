# 📊 SQL Queries — Portfólio

Repositório com exemplos de consultas SQL que reflete o tipo de trabalho que faço no dia a dia como responsável pelo setor de T.I na **Speers Foods**, dando suporte e extraindo dados do ERP **TOTVS Winthor** e do **CRM/SFA** para análises e apresentações à presidência da empresa.

> ⚠️ **Nota:** as tabelas, nomes e dados usados aqui são **fictícios**. O objetivo é demonstrar domínio das construções de SQL mais usadas no meu dia a dia (SELECT, WHERE, JOIN, AND, AS, LIKE, UPPER, GROUP BY, entre outras), sem expor nenhuma informação real ou sensível da empresa.

## 🗂️ Estrutura

| Arquivo | Conteúdo |
|---|---|
| [`schema.sql`](./schema.sql) | Estrutura de tabelas de exemplo (clientes, produtos, pedidos, itens_pedido) |
| [`01_consultas_basicas.sql`](./01_consultas_basicas.sql) | SELECT, WHERE, AND, LIKE, UPPER, AS — filtros e buscas simples |
| [`02_consultas_com_join.sql`](./02_consultas_com_join.sql) | JOIN entre múltiplas tabelas para relacionar pedidos, clientes e produtos |
| [`03_consultas_analiticas.sql`](./03_consultas_analiticas.sql) | Consultas agregadas (SUM, COUNT, GROUP BY) para relatórios de gestão |

## 🎯 Contexto de uso

No dia a dia, esse tipo de consulta é usado para:

- Levantar informações de clientes e pedidos para suporte a usuários internos e externos
- Gerar bases de dados para relatórios em Excel e apresentações em PowerPoint
- Apoiar decisões da diretoria com dados de faturamento, estoque e produtos mais vendidos
- Auxiliar na implementação e validação de dados durante a migração para o **TOTVS N3URONS**

## 🛠️ Comandos SQL demonstrados

`SELECT` · `FROM` · `WHERE` · `JOIN` · `AND` · `AS` · `LIKE` · `UPPER` · `GROUP BY` · `ORDER BY` · `SUM` · `COUNT` · `DISTINCT`
